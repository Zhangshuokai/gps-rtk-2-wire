## 2. 关键证据原文

模块固件自报（README §2.1，实测抓包）：

```
$CONFIG,COM1,CONFIG COM1 115200
#VERSION,96,GPS,UNKNOWN,1,296300,23575,0,18,78;UM982,R4.10Build23575,HRPT00-S10C-P,2310415000002-LR21B5241803223,ff3be38e6856fcce,2026/02/11
```

`#VERSION` 体字段顺序（本项目解析）：型号 / 固件 / 产品串 / 序列号 / 哈希 / 构建日期。

判定「真实型号」的关键点：

1. **PN 佐证**：UM982 用户手册 §5.1 声明该手册适用的 PN 为 `2310415000002` 与
   `2310415000012`；本机序列号 `2310415000002-LR21B5241803223` 以 `2310415000002` 起头。
2. **定向能力佐证**：设备在 `MODE ROVER UAV` 下同时输出 `#UNIHEADINGA` 与 `$GPTHS`，
   且 `LOGLIST` 三个端口均配置了定向日志——UM980 无此定向解算能力。
3. **不可混淆**：SparkFun 库面向 **UM980**；本机是 **UM982**，双天线定向语义不能照搬。

## 3. 评估板 / 连接方式

官方评估板为 **UM982eb**（User Manual CH R1.2，已归档）。其对外接口是 **28-pin、2 mm
双排插针**（可直接对插 HPL EVK-V5.0 的 J18），评估板本身**没有板载 USB**。
因此本机是在模块/评估板的 `COM3` 上用一颗 **CH340 USB 转 TTL** 适配器接到电脑。
这一点很重要：模块自报的 `COM1/COM2/COM3` 是**模块自己的 UART 编号**，
Windows 上的 `COM10` 只是 CH340 在本机的枚举名，两者不是同一回事。

## 4. 硬件要点（摘自厂家文档）

* 3 × UART（LVTTL）；UART3 可复用为 CAN；SPI / I2C 为预留（特定固件才支持）。
* 供电 3.0–3.6 V（典型 3.3 V），典型功耗 500 mW（双天线 10 Hz PVT+RTK+Heading）。
* 主天线频点全系统全频；从天线仅 BDS B1I/B2a/B3I、GPS L1/L2、GLONASS G1/G2、
  Galileo E1/E5b、QZSS L1/L2 —— **主从天线可见频点不同**，排障时注意。
* 天线馈电由板外提供（ANT_BIAS 与 VCC 建议不同电源轨）；评估板含 5 V 升压与天线短路保护。
* PPS 精度 20 ns；秒脉冲脉宽/极性可调。
